<h2 id="what-the-sdk-provides">What the SDK Provides</h2>
<p>The SDK bridges the gap between a compiled contract artifact and a live transaction on the BSV blockchain. It handles:</p>
<ul>
<li><strong>Contract instantiation.</strong> Load a compiled artifact, provide constructor arguments, and get a contract instance with a fully resolved locking script.</li>
<li><strong>Deployment.</strong> Build and broadcast a transaction that locks funds into the contract’s locking script.</li>
<li><strong>Method calls.</strong> Construct spending transactions that satisfy the contract’s conditions.</li>
<li><strong>State management.</strong> For stateful contracts, serialize and deserialize state, track continuation UTXOs, and build state transition transactions.</li>
<li><strong>Token operations.</strong> Transfer, merge, and burn fungible and non-fungible tokens.</li>
<li><strong>Fee calculation.</strong> Estimate transaction fees, select UTXOs, and compute change outputs.</li>
</ul>

<h2 id="signers">Signers</h2>
<p>Signers produce cryptographic signatures for transaction inputs. They never expose the private key to the SDK — they receive the full transaction hex, input index, subscript, and satoshis, and return a DER signature.</p>
<h3 id="localsigner">LocalSigner</h3>
<p>Signs transactions using a WIF-encoded private key stored in memory.</p>
<pre class="astro-code astro-code-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8;overflow-x:auto" tabindex="0" data-language="typescript"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">import</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> { LocalSigner } </span><span style="color:#D73A49;--shiki-dark:#F97583">from</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> &#39;runar-sdk&#39;</span><span style="color:#24292E;--shiki-dark:#E1E4E8">;</span></span>

<h2 id="deployment-flow">Deployment Flow</h2>
<p>The typical workflow from compilation to deployment:</p>
<pre class="astro-code astro-code-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8;overflow-x:auto" tabindex="0" data-language="plaintext"><code><span class="line"><span>1. Compile       runar compile src/contracts/P2PKH.runar.ts --output ./artifacts</span></span>
<span class="line"><span>                 Produces: artifacts/P2PKH.json</span></span>
<span class="line"><span></span></span>
<span class="line"><span>2. Instantiate   const contract = new RunarContract(artifact, [pubKeyHash])</span></span>
<span class="line"><span>                 SDK fills constructor placeholders in the script</span></span>
<span class="line"><span></span></span>
<span class="line"><span>3. Deploy        const result = await contract.deploy(provider, signer, { satoshis: 10000 })</span></span>
<span class="line"><span>                 Builds tx, signs funding input, broadcasts</span></span>
<span class="line"><span>                 Returns: { txid, tx }</span></span>
<span class="line"><span></span></span>
<span class="line"><span>4. Call          const result = await contract.call(&#39;unlock&#39;, args, provider, signer)</span></span>
<span class="line"><span>                 Builds spending tx, signs, broadcasts</span></span>
<span class="line"><span>                 Returns: { txid, tx }</span></span></code></pre>
<p>For stateful contracts, step 5 can be repeated multiple times, with each call producing a new UTXO that carries the updated state.</p>
<h2 id="reconnecting-to-a-deployed-contract">Reconnecting to a Deployed Contract</h2>
<p>If you already deployed a contract and need to interact with it in a new session, use <code>fromTxId</code>:</p>
<pre class="astro-code astro-code-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8;overflow-x:auto" tabindex="0" data-language="typescript"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">const</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> contract</span><span style="color:#D73A49;--shiki-dark:#F97583"> =</span><span style="color:#D73A49;--shiki-dark:#F97583"> await</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> RunarContract.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">fromTxId</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">  artifact,</span></span>
<span class="line"><span style="color:#032F62;--shiki-dark:#9ECBFF">  &#39;a1b2c3d4e5f6...&#39;</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#6A737D;--shiki-dark:#6A737D">// deployment txid</span></span>
<span class="line"><span style="color:#005CC5;--shiki-dark:#79B8FF">  0</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,                   </span><span style="color:#6A737D;--shiki-dark:#6A737D">// output index</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">  provider,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>This fetches the transaction from the network, extracts the locking script and satoshi value from the specified output, and reconstructs the contract instance. For stateful contracts, it also deserializes the state from the script.</p>

<h2 id="sdk-and-compiler-version-compatibility">SDK and Compiler Version Compatibility</h2>
<p>The SDK reads the <code>version</code> field in the artifact JSON to determine compatibility. The current SDK version (<code>0.1.x</code>) is compatible with artifacts that have <code>version: &quot;runar-v0.1.0&quot;</code>.</p>
<p>If you upgrade the compiler and the artifact format changes, you will also need to upgrade the SDK. The SDK will throw a clear error if it encounters an artifact version it does not support.</p>
