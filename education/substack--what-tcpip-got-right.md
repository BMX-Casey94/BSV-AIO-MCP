# What TCP/IP Got Right — core principles

- **A credibly fixed base layer is the precondition for cumulative investment above it.** Fixedness is not immutable, static, inflexible or governance-free: change is possible but constrained; innovation is channelled upward; the extension space responds to needs. The operative property is credibility across the relevant investment horizon.
- **TCP/IP is an existence proof, not an accident of age.** IPv4 core semantics have been stable since the early 1980s; TCP extends through its defined option space; QUIC and SCTP were added alongside TCP rather than revising it. The base layer accommodated them by not changing.
- **The institutional ingredients are known.** IETF rough consensus and running code; staged RFC review requiring demonstrated implementations; backwards compatibility as a norm (an incompatible change is a new protocol, not a revision); the end-to-end principle; authority distributed across IETF, IEEE, W3C, ICANN and registries; multiple independent implementations; a deep, slow-moving installed base.
- **The hourglass model locates stability at the waist.** A narrow set of protocols everything must support is where fixedness belongs; the wide application top is where innovation belongs. Base-layer fixedness is what permits upper-layer freedom.
- **Mutable base layers produce shallow application layers.** Firms specialise capital to stable semantics. If a coalition could rewrite the packet format quarterly, investors hedge or accept stranded investment, expected returns fall, and the hourglass collapses.
- **Settlement layers with minimal primitives attract longer-horizon investment.** Transaction validation, ordering and settlement, with rare, deliberate, broadly consented change, outperform rich Turing-complete bases that force protocol revision whenever needs evolve.
- **The costs of fixedness are real and situational.** Design errors are hard to correct; some beneficial changes become institutionally impossible. Young systems with uncertain requirements should not commit prematurely.
- **Stability is recursive.** Stability attracts investment; investment produces an installed base; the installed base reinforces stability. Slow is the point: the slowness of standards processes is the mechanism that produces credibility.
