<p>The primary entry point. Takes a source string and returns a compiled artifact.</p>

<h2 id="parse">parse()</h2>
<p>Parses a Runar source string into a <code>ContractNode</code> AST. The parser is auto-dispatched based on the <code>fileName</code> extension (<code>.runar.ts</code>, <code>.runar.sol</code>, <code>.runar.move</code>, <code>.runar.py</code>, <code>.runar.go</code>, <code>.runar.rs</code>). Does not perform validation or type checking.</p>
