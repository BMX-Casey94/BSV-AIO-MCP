# The Geography of Discretion — core principles

- **A set-in-stone base layer is a commitment device.** Wire format, consensus rules and canonical ledger semantics that cannot be revised after deployment let participants plan, invest and contract around stable rules — the constitutional function of a protocol.
- **What is fixed is only the base layer.** Application-layer evolution above a frozen wire format and UTXO semantics is the point of the condition, not a concession.
- **TCP/IP is the institutional comparator.** RFC 793's 1981 wire format and connection state machine have never been revised; later RFCs populate reserved option fields. Filling a reserved field is use, not revision — the same extension pattern Bitcoin designed with reserved Script opcodes.
- **Emergency forks are Schmittian sovereignty.** Once an exception-fork precedent exists, every contested situation becomes a potential emergency; the implicit knowledge that a coalition will rewrite history is itself a tax on every subsequent commitment.
- **Fixedness without independent implementations is paper.** Multiple independent clients (a drifting stack loses interoperability) and disciplined multi-vendor extension (the IETF model) are the conditions that make immutability more than rhetoric.
- **Immutability relocates discretion; it does not abolish it.** Exchanges, regulators and courts remain; constitutionalism claims only that discretion there operates slower, more public and more constrained by precedent. A regulator cannot change monetary policy by issuing a regulation.
- **The refined claim is conditional and testable.** Fixed: wire format, consensus rules, ledger semantics. Required: multiple implementations, disciplined extension, no coalition with effective rule-changing authority. Constrained: protocol-layer discretion only.
- **The real choice is adaptability above a fixed base versus discretion all the way down.** There is no discretion-free zone on the map; the geography of discretion is the design problem.
