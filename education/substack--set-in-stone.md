# Set in Stone — core principles

- **Competition relocates when a design channel is closed.** If foundations can be altered, altering them becomes a competitive strategy and rational firms invest in influence. If they cannot, the same money is forced into engineering — what we normally call innovation.
- **A frozen specification is the ground, not the prize.** 3GPP Releases freeze after functional, stage-3 and protocol code freezes; Release 15 devices keep working under Release 17, and nobody can lobby to change Release 15. Competition moves to implementation quality, efficiency, cost and applications.
- **Mutability concentrates power.** A fixed rule is equally binding on and knowable by everyone; a mutable rule is knowable only to those in the room. Flexibility is sold as democratic and functions as oligarchic, because the capacity to exploit flexibility is distributed far more unequally than the capacity to read a fixed document.
- **Fixed is not frozen at the edge.** The end-to-end argument put application functions at the endpoints; the hourglass keeps a narrow fixed waist. Additive versioning adds to a release and never modifies it. Innovation belongs at the edge, where workarounds are voluntary, competitive and reversible.
- **The original Bitcoin design was complete.** Script fully enabled, block capacity unbounded by protocol, no upgrade mechanism, no governance — because the rules are not in question. Escrow, bonded contracts and multi-party signature were designed in at the beginning so the base need never change.
- **Forks are the predictable output of contestable rules with no terminal decision procedure.** A fixed base cannot fork over rule disputes because none arise. Repair at the edge is reversible; base amendments are compulsory, monopolistic and permanent.
- **Stable architecture makes deep specialisation rational.** Where the ground does not move, you cannot buy a position — you have to earn one. Instability pushes engineering from deep to shallow.
- **Freeze the base and make every attestation layer checkable from the record itself.** A public immutable ledger is the verification layer that self-declared, unadjudicated standard-essential-patent regimes lack.
