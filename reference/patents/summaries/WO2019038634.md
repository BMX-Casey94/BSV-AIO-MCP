## Problem addressed
The specification says symmetric stream ciphers need a shared seed that is hard to deliver safely over an open network, while Diffie–Hellman-style asymmetric establishment is too expensive when new secrets must be generated continuously, and is poorly suited to high-speed streaming or large transfers. It wants a method that is both highly secure and fast enough for media streaming, streamed VPNs and large files, and that is easy to set up.

## Core mechanism
Two nodes each hold an elliptic-curve master key pair. A public message M (for example Unix time plus a nonce) is hashed to a deterministic key DK; each node derives session keys V2 = V1 + DK and P2 = P1 + DK × G and computes the same common secret CS = V2C × P2S = V2S × P2C without transmitting CS. CS (or a converted symmetric key) is combined with additional data that includes a time variable, or a cryptographic function of a time variable, to form a secret key. That key seeds a pseudo-random number generator; the PRNG output is combined with the plaintext (for example by XOR) to produce a stream cipher that is sent to the other node. The same CS can be re-derived from stored M and the master keys; ECDSA on M authenticates the sender.

## Independent claims (gist — not legal scope)
Independent claim 1 is a method of encrypting and transmitting data from a first node to a second: derive a secret key from a common secret that both nodes compute from their asymmetric key pairs without sending the secret; use that key as a PRNG seed; combine PRNG output with the data; and transmit the ciphertext, the secret key being the common secret (or a conversion of it) combined with additional data that includes a time variable or a cryptographic function of a time variable.

## BSV relevance
The specification names Bitcoin-style hierarchical keys and gives a blockchain media-streaming example in which films stored on a blockchain are streamed to users with payment in cryptocurrency. The same common-secret and stream-cipher construction could carry encrypted payloads to or from BSV applications.
