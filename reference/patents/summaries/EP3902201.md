## Problem addressed
The specification says public ledger data, even after coin mixing, still carries latent patterns that traffic or timing analysis and machine learning can use to link addresses to a common owner. Third-party mix coordinators add a further leak surface. It seeks to raise the entropy of mixing so that a monitor is less able to assign unequal probabilities to which participant originated which output.

## Core mechanism
Blinded Outcome Diversification runs among at least four participating nodes. A dealer orders the nodes and, for each cycle, randomly assigns a distinct originator, selector and propagator. The originator builds at least two nested-encrypted transaction options that sum to the same input value — typically one output versus a split into two outputs — encrypted first with a propagator-generated transaction public key and then with the participants’ public keys in reverse order. Each node strips its own layer. The randomly chosen selector, without reading the plaintext, keeps only one encrypted option and forwards it. The propagator decrypts the chosen option with the transaction private key and emits a propagator output (addresses and values re-encrypted to its public key). Propagator outputs from every cycle are then shuffled by a coin-mixing encryption/decryption phase so the number of output addresses can exceed the number of inputs.

## Independent claims (gist — not legal scope)
Independent claim 1 is a method in which a participating node receives ciphertext, and either (as selector) chooses a subset, decrypts that subset with its private key and forwards the opted ciphertext, or (otherwise) decrypts the whole ciphertext with its private key and forwards the result. Independent claims 13 and 14 cover a computing device and a non-transitory medium that carry out that method.

## BSV relevance
The protocol is a Bitcoin-compatible mixing construction that varies output cardinality at random. It bears on BSV only where developers implement collaborative mixing or address-unlinkability on the public ledger.
