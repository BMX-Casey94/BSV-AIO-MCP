# Set in Stone or Sold to the Highest Bidder — core principles

- **Immutability is the only defence against capture.** The system is either set in stone, or it is rewritten by the deepest pockets. Code that cannot change is the only thing that resists money; if it bends, it will eventually kneel.
- **Bitcoin was built for verifiable payment, not anonymity.** It was engineered to move digital value cleanly, without the institutional drag of banks that freeze and processors that strangulate — a settlement system that lights the room so every transaction can stand as a witness.
- **Pseudonymity is accountability without exposure.** Anonymity is the enemy of honest markets: you cannot run poker if five of six players are sock puppets for the same person. Mixers, tumblers and zero-knowledge cloaks are trojan horses that invite a "cleaner" clone marketed as progress.
- **Every mutable upgrade is a precedent for rewrite.** Each change makes the system more complex, more obscure, and more dependent on experts — a hostage situation with better branding. Fix the rules, and never touch them again.
- **Fiat integration was design, not betrayal.** Satoshi's 2009 note to Martti Malmi anticipated cash-backing and self-censored until the system was ready: Bitcoin was not to be gold, but to be fire.
- **What's immutable cannot be owned.** What's fixed cannot be bought. Bitcoin should be boring, blunt, and exactly the same tomorrow as it was in 2009 — protocol immutability as a business guarantee, not a slogan.
