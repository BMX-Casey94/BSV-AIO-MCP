# Quantum Illusions — core principles

- **Cryptography is binary; approximation is failure.** RSA rests on factoring, ECC on the discrete logarithm, SHA-256 on one-way hashes. A single bit out of place renders the output meaningless; a computation that is 99.9% correct is indistinguishable from one that is wholly wrong.
- **Random Circuit Sampling is a hardware-fidelity benchmark, not an algorithm.** It tests whether an output distribution resembles an ideal device; partial fidelity counts as success. Sampling progress says nothing about inverting a one-way function — a category error.
- **A theoretical path is not a physical road.** Shor's algorithm is mathematically sound, but breaking RSA-2048 would require an estimated 20 million physical qubits, error rates below 10⁻¹⁵ per gate, and trillions of coherent operations. Current microsecond coherence, 10⁻²–10⁻³ gate errors and 99–99.9% fidelities make a one-in-a-thousand error per gate certain failure after a few thousand gates.
- **Ownership on Bitcoin is functional: whoever can sign, owns.** A quantum-derived key would produce a signature indistinguishable from the owner's. The blockchain records outcomes, not motives; there is no protocol-level standard by which such a transaction could be judged theft.
- **Forced "quantum recovery" is confiscation framed as protection.** Pre-emptive transfers of "vulnerable" coins rewrite consensus rules, reintroduce human arbitration, and destroy the neutrality that defines the system.
- **Fear, not the qubit, is the instrument of control.** A funding–headline–fear cycle times milestones to investment and national-security programmes; the narrative is used to legitimise coercion in the name of protection.
- **Even hypothetical quantum key recovery would obey the rules, not break them.** It would merely execute them faster. Altering consensus to seize others' coins is the actual attack on the system's integrity.
