# Misconceptions surrounding copyright — core principles

- **Paying for a work does not transfer its copyright.** Copyright requires an explicit transfer of rights; commissioning a report does not make it the commissioner's property absent an express assignment clause.
- **Default ownership rules are intricate.** Under s 35(4) of the Australian Copyright Act 1968, even an employed journalist retains rights for selected purposes (book compilation, photocopying) while the employer keeps the remaining rights; defaults can be varied "through agreement and by assignment [ss 35(3), 97(3), 98(3), 179]". Ownership must be checked case by case — never assume it lies with creator, commissioner or employer.
- **Joint authorship splits by contribution.** Where contributions are indistinguishable the work is jointly owned; where authors contribute separable parts (e.g. chapters), each holds copyright in their own input — and each joint author can make derivative works using the whole.
- **Bitcoin is an immutable timestamping system.** A creator can save a hash of a work on the blockchain indefinitely, giving durable proof of existence and priority.
- **Smart contracts can administer rights on-chain.** "Bitcoin will allow the creation of complex smart contracts that can be used to allocated and assign rights within a defined and agreed set of terms that are indexed or attached in an OP_RETURN."
- **Component-level licensing becomes automatic.** One author's part under an MIT licence, another's under standard copyright — executed "automatically and with complete autonomy", with global monitoring of derivative use.
- **On-chain registers support corporate IP hygiene.** A complete register of all copyright can be maintained with IP recorded in hashed format on-chain, so an employer can instantly know if an employee is sharing or accessing unlicensed material.
- **Fair use can be algorithmically metered.** Academics would know when they near the fair-use boundary, and any excess use can be instantly licensed and the rights assigned for consideration.
