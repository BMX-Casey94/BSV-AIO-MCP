# A Fundamental Misunderstanding — core principles

- **A new key pair should be used for each transaction.** The white paper’s firewall keeps transactions from being linked to a common owner. A single fixed-key bearer card violates that privacy design.
- **Physical bearer cards reintroduce custodial trust.** Users must trust the manufacturer never to save the keys — the assumption Bitcoin was built to remove.
- **Physical security has a price.** If keys can be extracted and the coating reapplied for a few dollars in bulk, the card is economically and physically insecure, and infeasible for small payments.
- **Walk-around and net-around money are different use cases.** 1990s FATF taxonomy distinguished online e-cash from face-to-face prepaid cards. A product that tries to be both satisfies neither.
- **AML already covers this category.** Laws covering prepaid electronic-cash products were introduced when Mondex appeared; novelty claims ignore that history.
- **Bitcoin is designed to be an electronic cash system.** Digital coins based on a template saved to the blockchain, built for micropayments — not a metal card pretending to be cash.
