# The labour fallacy of mining — core principles

- **Labour is a means, not a goal.** There is no fixed labour pie. "We DO NOT work to work, but rather for what we can obtain." Equalising labour leaves everyone equally poor; productivity, not distributed work, creates wealth. Making more work is easy — salt the fields, smash the machines.
- **Bitcoin is a commercial, lawful, auditable system.** It was built for "logistics systems, EDI, payment, voting, and much more," with corporations and the state as users — "an evidentiary system that allowed monetary exchange with traceability that acted within the law." Its origin was audit simplification, not a crisis protest.
- **The incentive model does not allow a protocol change.** Any new addition splits from the network while SPV users continue on the original. "The reason the protocol doesn't change is that it is outside the purview of nodes to alter it."
- **A 51% attacker cannot rewrite Bitcoin.** He "needs to mislead users into thinking that the new protocol is Bitcoin"; at best he can double-spend his own transactions, leaving "an immutable evidence trail — which is admissible under law."
- **Only miners run nodes.** "A node creates a block." Merchants validate received transactions via SPV, keep copies as receipts and invoices admissible in court, and can detect double-spends "within seconds" and detain the person violating the law as a shop detains a shoplifter.
- **Nodes vote on which transactions to build upon, never on protocol changes.** A protocol change creates an alternative system; an airdrop of copied balances misleads consumers.
- **Bitcoin is not high-powered money.** It scales through corporate competition and will create large global firms. Security comes from well-capitalised competing corporations, not from equalising home miners.
