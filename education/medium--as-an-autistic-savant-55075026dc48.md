# As an Autistic Savant… — core principles

- **Bitcoin Script is a predicate.** A validated script can be true, false, or syntactically invalid. Only a syntactically correct predicate yields a binary outcome.
- **Partial branches are not automatically false.** A branching script can be syntactically invalid for some inputs yet return a valid true or false for others. It is a fallacy to treat a syntactically incomplete scenario as necessarily false.
- **A true result can sit on a bad argument.** Fallacious reasoning (for example, a bandwagon claim) does not by itself invalidate the associated result; the conclusion and the argument must be judged separately.
- **To be Bitcoin, the protocol must be stable.** It is not a system with forks. A forked chain is, by that definition, not Bitcoin.
- **Bitcoin is lawful micropayment cash.** The design is a cash system focused on micropayments that acts within the law and cannot act outside it.
- **The system never runs without people.** Bitcoin was never, and can never be, a system that runs without human interaction.
