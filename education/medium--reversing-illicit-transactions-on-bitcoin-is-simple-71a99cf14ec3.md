# Reversing Illicit Transactions on Bitcoin Is Simple — core principles

- **Bitcoin was designed inside the law, not against it.** The claim that it was created as an anarchist system opposed to government and banks is a false reading of the design.
- **Nodes are miners, not every user.** A node is a function of the verification system — miners — not a requirement that each user run a full replica of the network.
- **Users rely on Simplified Payment Verification.** White-paper section 8 is the design: ordinary users do not each hold a network node.
- **Illicit transfers can be reversed within law.** Because Bitcoin sits inside the legal system rather than outside it, reversing illicit transactions is a tractable legal-and-mining problem, not a metaphysical impossibility.
- **Immutability is not a shield for crime.** Transaction finality does not mean courts and miners are powerless to restore stolen or illicitly obtained coins.
- **Do not redefine Bitcoin as bit gold.** Substituting an army of computers for accountants, investigators and lawyers is a different project; Bitcoin does not replace law.
