# The History of Freezing in Bitcoin — core principles

- **Freezing was native to the design.** The white paper’s alert mechanism, and the same protocol that distributes blocks and transactions, lets nodes warn one another of events; SPV wallets were to be protected by alerts from nodes.
- **Nodes are miners.** The hard problem is which nodes to trust — a voting-strategy question among miners, not among users. UASF “nodes” do not exist; any system that does not mine a block is not a node.
- **Decentralisation means reliability.** The peer network exists to gain resilience and increase security, not to build an anarchist system outside government. The Haber/Stornetta timestamp lineage is the technical ancestor.
- **Rules were set at creation.** Bitcoin is not democratic. No cryptographic protection attaches to how many coins one holds.
- **Keys are not the coins.** A bitcoin designates 100 million indivisible digital tokens. What you own are the chattel property rights in each token, held in UTXO envelopes. Possession is not ownership.
- **Honest nodes enforce court orders.** Nodes enforce rules; a court order is a rule; honest nodes reject blocks that do not enforce the rules. The 100-block coinbase maturity window allows valid orphaning of blocks that violate an order.
- **Pool operators are the nodes.** Members of a pool do not set the rules; the operator does. Large nodes are easily detectable; anonymous mining at scale is not how the system was designed.
- **A minority fork around a freeze is worthless.** An alternate chain that flouts freeze orders would be illegal on any regulated exchange and almost completely valueless; receipt of stolen property is a crime.
- **Bitcoin is completely traceable and can be frozen.** It will therefore never serve illicit markets. Bitcoin does not stop governments issuing orders against nodes.
