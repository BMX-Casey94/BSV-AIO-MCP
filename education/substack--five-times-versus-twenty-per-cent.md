# Five Times Versus Twenty Per Cent — core principles

- **Opening the edge multiplies innovation; opening the base does almost nothing.** Granting complementors access was associated with up to a fivefold acceleration in new device development; devolving control of the platform itself yielded roughly twenty per cent — an order of magnitude smaller, and often insignificant.
- **The operative variable is the cost of changing the rules relative to the cost of building at the edge.** Competition relocates rather than disappears. A body that demands multiple working interoperating implementations makes rule change expensive while building stays free.
- **Adherence to a fixed design rule is a substitute for governance — but only while the rule is fixed and known.** Designs split into visible design rules and hidden modules. A changeable rule is an object of governance, and coordination costs return as anticipation, lobbying or hedging.
- **Every detail exposed in a fixed interface shrinks the set of systems buildable without changing it.** Information hiding lets independent work begin early. Over-specification forces renegotiation. Module boundaries are thin crossing points: entrants only need to build a better module.
- **Fixity was the original Bitcoin design premise.** Once version 0.1 shipped, the core design was set in stone for the rest of its lifetime. Special-purpose transaction types end in an explosion of special cases; a general predicate script — escrow, bonded contracts, third-party arbitration, multi-party signature — was designed in at the beginning so the base need never change.
- **A change to a visible design rule lands on every module at once.** When a base layer moves, the party who pays is the co-inventor at the edge, in destroyed, non-transferable understanding. Committee governance with no requirement that anything be built first makes rule change cheap and invites capture.
- **Where the ground does not move, committing years to one competence is a bet on yourself.** Where it might move, the same commitment is a bet on a committee. "Open" is not one axis: access at the edge and control of the base are different properties.
