# Scenario 4: Rolling Contract — core principles

- **Rolling contracts express default-renewal logic on-chain.** An auto-renewing agreement (e.g. an annual laptop lease) is modelled as a state machine whose default transition is renewal rather than termination.
- **Notice windows are guarded transitions.** Termination requires active notice — two months' notice before the renewal date — failing which the contract automatically rolls on.
- **Silence maps to consent.** The state-machine model mirrors contract law's treatment of inaction as consent to renewal: default rules execute unless a party acts within the notice window.
