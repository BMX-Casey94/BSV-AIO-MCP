# Panopticrypt — core principles

- **Bitcoin is a panoptic-yet-cryptic ledger.** It shows the whole at one view while remaining cryptic enough for the system to be private.
- **Incentives control everything we do.** Applied correctly, economics creates a system that evolves toward something better; fitness is adaptation to the system, not raw power.
- **Anarchy is not an option.** There is no privacy in anarchy: without law the strong, the powerful and the wilful survive and take control.
- **Total surveillance is the other failure mode.** A central Panopticon review is not the answer; Bitcoin changes the balance by making corruption and fraud costly rather than impossible.
- **Seeking anonymity removes that strength.** Privacy is preserved through law and pseudonymity on a visible ledger, not by hiding from it.
- **A hash puzzle can bind any chosen output.** Individuals can select any output address yet simultaneously create a secure hash puzzle — a construction available in the original 2009 code.
- **Bitcoin is a building block, not the whole invention.** The ledger is a Lego piece needed in the creation of a larger data network (the Metanet).
