## Problem addressed
The specification argues that Bitcoin offers only pseudonymity: public addresses, common-input heuristics, IP linkage and machine-learning over user habits (timing, amounts, mixing use) can re-identify spenders. Mixing services and extra key pairs do not reliably break those patterns. The invention uses a first party’s random choice to randomise which output a second party spends.

## Core mechanism
In an initialisation phase both parties generate n secrets and publish only elliptic-curve points (secret × G). The second party forms n cryptographic locks as linear combinations of the two encrypted secret sets; the first party checks a homomorphic sum so the locks are well-formed without learning the second party’s secrets. In the commitment phase the second party posts a transaction with n outputs, each locked to one combined key (and typically also to the second party’s own key). After verification the first party randomly reveals one of its secrets. The second party adds that secret to its matching secret to obtain the private key of exactly one output, then spends that output in a payment transaction. Unused outputs can be refunded with the second party’s own key. Which output is used is therefore chosen by the first party and is not predictable from the second party’s usual behaviour.

## Independent claims (gist — not legal scope)
Claim 1 is a two-party security method: encrypted versions of n secrets from each party are combined by the second party into n locks corresponding to n transaction outputs; the second party receives one secret chosen at random by the first party; and the second party generates the key that unlocks the lock matching that secret. Claims 14 and 15 are a storage medium and an electronic device that perform the method.

## BSV relevance
The embodiment randomises which of several Bitcoin-style UTXOs is spent, using ECC-combined keys and a verifier who never sees the spender’s secrets. That is relevant to BSV wallet behaviour that seeks to break simple output-selection linkage.
