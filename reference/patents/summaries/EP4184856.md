## Problem addressed
The specification says a conventional hash puzzle reveals the preimage on the chain, so a miner can steal the spend unless the lock is also tied to a predetermined public key (P2PKH). That tie means the spender must be chosen when the first transaction is written. It seeks a knowledge proof that anyone who knows a secret can redeem, without publishing that secret and without locking the output to a named identity.

## Core mechanism
An “r-puzzle” puts a reference r-part (or a hash of r, optionally concatenated with extra data d) into runnable code on a first transaction. A second transaction supplies at least the s-part of an ECDSA signature (and often r, a public key P, and the signed message m, which is part of the second transaction). The code runs an ECDSA verification and returns true if s corresponds to the reference r, given m and P — regardless of which private key produced the signature. Knowledge of the ephemeral key k (where r = [k·G]x) is thereby proved without revealing k. Variants include checking a submitted r against the reference, a joint-value puzzle on f(r, d), multiple r statements, an r-puzzle forward chain, and optional extra signatures or locktime. The same idea is described for UTXO locking scripts and for account-based smart contracts.

## Independent claims (gist — not legal scope)
Independent claim 1 is a method at a verifying node: obtain a first transaction whose code specifies a reference r-part, receive a second transaction containing at least an s-part, obtain a public key, and run the code so that it returns true, irrespective of whose private key was used, if ECDSA verification shows that s corresponds to that reference r given the message and public key. Independent claim 15 is a set of two such transactions embodied on a computer-readable medium.

## BSV relevance
The puzzle is specified in Bitcoin Script (OP_CHECKSIG and related opcodes) so that a UTXO can be spent by anyone who knows k. That is a native BSV Script pattern for identity-agnostic knowledge proofs.
