# Coin burning for dummies — core principles

- **Scarcity alone does not set the price.** The total money supply is not only Bitcoin but all money; if there is a substitute, it is part of the supply. Value is demand at the margin, and that requires use.
- **Use and circulation, not hoarding, set long-term value.** Speculation adds volatility and is necessary, but liquidity comes from coins in active use; of a fixed stock, the market is priced by the circulating remainder.
- **Losing coins is not the same as burning them for a token.** Lost keys shrink the active bitcoin supply and can raise the exchange value of what remains; burning bitcoin for a substitute leaves total money unchanged — the supply is merely altered.
- **A burn into an issuable token is digital fiat.** Once the burnt bitcoin is expended, a proof-of-stake token controlled by an issuer can be inflated without limit; that is not a set and limited system such as Bitcoin is designed to be.
- **A “burn address” must actually be unspendable.** If the destination is a real key-controlled address, the coins are not destroyed; they can be recovered or used to stage a later security scare.
- **Value is cash use, ledger use, and anything people pay for.** Not HODL and exchange substitution games. Miner fees, not a private tax on token issuance, are how the system is meant to be paid for.
