# Open Source — core principles

- **Bitcoin is open source for Kerckhoffs’ principle, not free-software ideology.** A well-designed cryptographic system should be constructed so that only the key needs to be secret. There should be no secrecy in the algorithm.
- **Open source is not the same as free software.** Open source means the ability to analyse source code and ensure the integrity of the system. That is not an attack on copyright or property rights.
- **Security by obscurity is snake oil.** Proprietary secrecy requires more secrets to be kept. The fewer secrets a system has, the more secure it can be.
- **Hiding code asymmetrically helps the attacker.** Source cannot be fully hidden. Not releasing it slows honest analysis without deterring attackers, so vulnerabilities take longer to find.
- **Nearly every cryptographic system has a vulnerability.** Public algorithms and peer review are required because of that fact — Kerckhoffs predates software itself.
- **Bitcoin is an open protocol for commercial construction.** It is designed so any organisation can build commercial applications on top. It is not anti-capitalist; it works with law.
