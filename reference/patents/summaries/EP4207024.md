## Problem addressed
The specification says an open ledger lets observers correlate coins across addresses, which harms fungibility and confidentiality. Existing mixers introduce a central service that can steal funds, leak input–output links, and undermine peer-to-peer control. It seeks a user-controlled group exchange that moves value from one of a user’s addresses to another while obscuring the link and without a mixing provider.

## Core mechanism
The claimed Group Random Exchange of the second type randomises n users (n > 2) into a cycle and elects an initiator. Each user chooses a random ki; the initiator also chooses ks. Payment channels are built in order around the cycle, each comprising a commitment transaction, a locktimed refund, and a payment transaction. Each channel uses a different secret: encrypted values Q_i live on the elliptic curve (Q_{i+1} = Q_i + k_{i+1}G), so revealing the payment secret on one channel lets the previous payer subtract their neighbour’s k and recover the next secret. The initiator starts execution by spending the last channel with sv_n = ks + k_1 + … + k_0; payments then cascade in reverse order. Refunds with staggered locktimes reclaim funds if the protocol stalls. The claimed invention excludes the first-type protocol that reused one hash-locked secret k on every channel.

## Independent claims (gist — not legal scope)
Independent claim 1 is a method that randomises users, builds a cycle of payment channels (commitment, refund, payment) with per-channel elliptic-curve secrets accumulated from each user’s ki, and executes the chain in reverse so each revealed secret lets the previous payer compute the next. Independent claim 6 is a blockchain-implemented system of n processor-based users configured to run that method.

## BSV relevance
The protocol is specified with Bitcoin payment channels, nLockTime refunds and script conditions that take a secret plus a signature. The same construction can be run on BSV if the goal is user-controlled address unlinking without a mixing service.
