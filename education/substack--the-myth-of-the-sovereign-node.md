# The Myth of the Sovereign Node — core principles

- **Section 5 defines the operational node as a block producer.** The entity collects transactions into blocks and expends computational effort to extend the chain. The mechanism securing consensus is economic cost, not voting.
- **Local rejection without competing proof-of-work is private disagreement.** A non-mining machine may refuse a block; unless an alternative economically significant chain is produced, the network continues unaffected. Validation alone does not alter network state. Block production does.
- **Miners respond to expected profitability.** Consensus emerges from economically rational block production (Kroll, Davey and Felten), not constitutional voting among passive observers.
- **Validation, settlement preference, listing policy and protocol enforcement are different things.** Collapsing them into "users enforcing the rules" is a category error. Consensus is not established by spectatorship.
- **"Economic node" is not a technical term.** Exchange, custodian, payment processor, merchant and user are distinct commercial roles. Influence through liquidity, settlement infrastructure and market access is commercial gravity, not a software veto over proof-of-work.
- **The trichotomy is the real system.** A node without economic influence changes nothing; an exchange without mining changes prices but not consensus directly; a miner without market demand mines economically worthless outputs. Miners, exchanges, merchants, custodians, liquidity providers and users form a multilayered competitive market.
- **Running a full node confers no governance authority.** Node operation is spectatorship unless backed by economically significant block production.
